    Read RFC 2 ↗Status & errata ↗

    RFC 2 describes primary-link requests over control link 0. When both hosts request the same link, the larger host ID keeps its allocation attempt; the smaller ID accepts it and restarts its own allocation. Missing or unexpected replies lead to error handling.

    A visible sequence helps learners reason about coordination and failure. It provides a small example to discuss before building a more complex distributed system.

    A teaching trace, not a complete NCP implementation. Link 7 and timeout values are examples; the host range is a teaching constraint. RFC 2 is an incomplete archive with its first page reported missing. Official index status: UNKNOWN (Legacy stream). This project is independent of the RFC Editor and IETF.

    Try it with someone

    A two-minute experiment

    Choose the collision scenario and step through it. Swap host IDs and repeat. Then select a missing reply. Explain why silence cannot count as a successful connection.
